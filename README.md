## 📚 Programs Covered

### 1. Two Sum
**File:** `Two sum.py`

**Description:**
Find the indices of two elements in an array whose sum equals a given target value.

**Example:**
- Input: `nums = [2, 7, 11, 15]`, `target = 9`
- Output: `[0, 1]`

**Concepts Learned:**
- Python lists and arrays
- Nested loops and element traversal
- Array indexing
- Target-based searching

**Learning Outcome:**
Learned how to identify pairs of elements that satisfy a given condition and return their indices.

---

### 2. Sort Colors
**File:** `sort colours.py`

**Description:**
Sort an array containing only `0`, `1`, and `2` in ascending order without using a built-in sorting function.

**Example:**
- Input: `[2, 0, 2, 1, 1, 0]`
- Output: `[0, 0, 1, 1, 2, 2]`

**Concepts Learned:**
- Array manipulation
- Sorting techniques
- Conditional statements
- Swapping elements

**Learning Outcome:**
Understood how to arrange array elements according to specific conditions and explored efficient sorting approaches.

---

### 3. Palindrome Array
**File:** `Palindrome Array.py`

**Description:**
Check whether an array reads the same forward and backward.

**Example:**
- Input: `[1, 2, 3, 2, 1]`
- Output: `Palindrome`

**Concepts Learned:**
- Python lists
- Array indexing
- Loops and conditional statements
- Forward and reverse comparison

**Learning Outcome:**
Learned how to compare array elements from opposite ends to determine whether an array is a palindrome.

---

### 4. Move Zeros
**File:** `Move zeros.py`

**Description:**
Move all zeros in an array to the end while maintaining the relative order of the non-zero elements.

**Example:**
- Input: `[0, 1, 0, 3, 12]`
- Output: `[1, 3, 12, 0, 0]`

**Concepts Learned:**
- Array traversal
- List manipulation
- Element rearrangement
- Two-pointer technique

**Learning Outcome:**
Learned how to rearrange array elements while preserving the order of non-zero values.

---

### 5. Add Two Numbers
**File:** `Add Two numbers.py`

**Description:**
Add two numbers represented by linked lists, where each node contains a digit. The digits are generally stored in reverse order, and the result is returned as a linked list.

**Example:**
- Input: `l1 = [2, 4, 3]`, `l2 = [5, 6, 4]`
- Output: `[7, 0, 8]`

**Explanation:**
The numbers represented are `342` and `465`. Their sum is `807`, represented in reverse order as `[7, 0, 8]`.

**Concepts Learned:**
- Linked lists
- Node traversal
- Addition with carry
- Handling different list lengths

**Learning Outcome:**
Understood how to perform digit-by-digit addition and manage carry values while working with linked lists.
